Install HabitForge

HabitForge is a Progressive Web App (PWA). It runs 100% offline directly from your device with zero cloud lag and full privacy.

ℹ️ Browser prompt standby. If the button does not trigger automatically, install via browser menu:

Manual Installation Steps:

  1. Open HabitForge in Chrome (Android/Desktop) or Safari (iOS).
  2. Tap browser menu (Three Dots or Share button).
  3. Select "Install App" or "Add to Home Screen".
  4. HabitForge will launch standalone in full-screen mode offline!
